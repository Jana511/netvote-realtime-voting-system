About NetVote

EC5205 Network Programming – group project.

The project

NetVote is a real-time networked polling and voting system. An administrator creates a poll with a question and several options, users vote from different computers or phones, and every connected screen shows the updated results immediately.

The system follows the client–server model: only the server stores the poll and counts the votes, so results are consistent for everyone and cannot be changed by a client.

Objectives

  • Let many clients connect to one server at the same time.
  • Allow exactly one vote per user per poll.
  • Send live result updates to all connected users.
  • Give the administrator control to create and close polls.
  • Keep working when a client disconnects, and save poll results.
